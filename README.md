# দোকান (Dokan) — Shop Management Website

Node.js + Express + Firebase (Auth / Firestore / Storage) দিয়ে তৈরি একটি ফুল-স্ট্যাক দোকান ওয়েবসাইট। Vercel-এ ডিপ্লয় করার জন্য প্রস্তুত।

## ফিচারসমূহ

- 🔍 পণ্য সার্চ (নাম দিয়ে বা **ইউনিক কোড** দিয়ে সরাসরি খুঁজে পাওয়া)
- 🛠️ অ্যাডমিন প্যানেল — পণ্য যোগ/এডিট/ডিলিট, ছবি আপলোড (Firebase Storage)
- 🏷️ প্রতিটি পণ্যে **ঐচ্ছিক ইউনিক কোড** (বাধ্যতামূলক না)
- 👥 **রিসেলার রোল** — অ্যাডমিন প্যানেল থেকে যেকোনো ইউজারকে রিসেলার বানালে সে ক্রয় মূল্য ও বিক্রয় মূল্য দুটোই দেখতে পাবে (সাধারণ গ্রাহক শুধু বিক্রয় মূল্য দেখবে)
- 📦 স্টক ট্র্যাকিং — অ্যাডমিন প্যানেল থেকে স্টক দেখা ও আপডেট করা যাবে
- 🔐 Firebase Authentication (ইমেইল/পাসওয়ার্ড) + সার্ভার-সাইড সেশন কুকি

## প্রজেক্ট স্ট্রাকচার

```
shop-app/
├── server.js                 # Express অ্যাপ এন্ট্রি পয়েন্ট
├── config/firebaseAdmin.js   # Firebase Admin SDK ইনিশিয়ালাইজেশন
├── middleware/auth.js        # সেশন যাচাই + রোল-বেসড অ্যাক্সেস কন্ট্রোল
├── routes/
│   ├── auth.js                # লগইন / সেশন / লগআউট
│   ├── products.js            # পাবলিক স্টোরফ্রন্ট + সার্চ API
│   └── admin.js                # অ্যাডমিন প্যানেল CRUD + রোল ম্যানেজমেন্ট
├── views/                      # EJS টেমপ্লেট
├── public/                     # CSS, JS, ইমেজ
├── utils/setAdmin.js           # প্রথম অ্যাডমিন বানানোর স্ক্রিপ্ট
├── firestore.rules / storage.rules
└── vercel.json
```

## ১. Firebase প্রজেক্ট সেটআপ

1. [Firebase Console](https://console.firebase.google.com/) এ গিয়ে নতুন প্রজেক্ট তৈরি করুন।
2. **Authentication** → Sign-in method → **Email/Password** চালু করুন।
3. **Firestore Database** → Create database (production mode) চালু করুন।
4. **Storage** → Get started করে একটি bucket তৈরি করুন।
5. প্রজেক্ট সেটিংস থেকে দুটো জিনিস সংগ্রহ করুন:
   - **Web app config** (Project settings → General → Your apps → Web app যোগ করুন) — এটা `PUBLIC_FIREBASE_*` এনভায়রনমেন্ট ভ্যারিয়েবলে যাবে।
   - **Service account key** (Project settings → Service accounts → Generate new private key) — এটা `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY`-তে যাবে।
6. Firestore ও Storage-এর সিকিউরিটি রুলস আপডেট করুন (Firebase Console-এর Rules ট্যাবে গিয়ে এই রিপোর মূল ফোল্ডারের `firestore.rules` এবং `storage.rules` ফাইলের কন্টেন্ট পেস্ট করে দিন)। এতে সব ডেটা অপারেশন শুধু আমাদের Node.js ব্যাকএন্ড (Admin SDK) দিয়েই হবে, ব্রাউজার থেকে সরাসরি Firestore/Storage-এ কেউ ঢুকতে পারবে না।

## ২. এনভায়রনমেন্ট ভ্যারিয়েবল

`.env.example` কপি করে `.env` বানান এবং নিজের Firebase তথ্য বসান:

```bash
cp .env.example .env
```

⚠️ `FIREBASE_PRIVATE_KEY` কপি করার সময় পুরো কোটেশনসহ কপি করুন — এর ভেতরে `\n` থাকবে, কোড নিজে থেকেই সেটাকে আসল নিউলাইনে রূপান্তর করে নেবে।

## ৩. লোকালি রান করা

```bash
npm install
npm run dev        # http://localhost:3000
```

## ৪. প্রথম অ্যাডমিন বানানো

1. ওয়েবসাইটে গিয়ে `/login` পেজ থেকে **"নতুন অ্যাকাউন্ট তৈরি করুন"** দিয়ে নিজের ইমেইল/পাসওয়ার্ড দিয়ে একবার সাইন-আপ করুন (এতে ডিফল্ট রোল `customer` হয়ে যাবে)।
2. এরপর টার্মিনালে এই কমান্ড চালান — এতে আপনার অ্যাকাউন্ট `admin` হয়ে যাবে:

```bash
node utils/setAdmin.js you@example.com
```

3. আবার লগইন করুন (লগআউট করে আবার লগইন) — এখন `/admin` প্যানেল দেখতে পাবেন।
4. এরপর থেকে নতুন কাউকে **রিসেলার** বানাতে চাইলে — Admin Panel → ইউজার ও রিসেলার → তার রোল ড্রপডাউন থেকে "রিসেলার" সিলেক্ট করে দিন। আর কাউকে অ্যাডমিন বানাতে হলেও একই জায়গা থেকে করা যাবে (আর টার্মিনাল স্ক্রিপ্ট লাগবে না)।

## ৫. পণ্য যোগ করা

Admin Panel → পণ্যসমূহ → নতুন পণ্য → নাম, ক্যাটাগরি, (ঐচ্ছিক) ইউনিক কোড, ক্রয়/বিক্রয় মূল্য, স্টক, ছবি দিয়ে সাবমিট করুন।

- ইউনিক কোড খালি রাখলেও সমস্যা নেই — এটা বাধ্যতামূলক না।
- কোড দিলে সিস্টেম চেক করে নেয় যেন দুটো পণ্যে একই কোড না বসে।

## ৬. Vercel-এ ডিপ্লয়

```bash
npm install -g vercel
vercel login
vercel
```

ডিপ্লয়ের সময় (অথবা Vercel Dashboard → Project → Settings → Environment Variables থেকে) `.env`-এর সব ভ্যারিয়েবল যোগ করে দিন। তারপর:

```bash
vercel --prod
```

`FIREBASE_PRIVATE_KEY` Vercel-এ বসানোর সময় পুরো স্ট্রিং (BEGIN/END লাইনসহ, `\n` সহ) এক লাইনে পেস্ট করুন — কোড নিজে থেকেই আসল নিউলাইনে কনভার্ট করে নেবে।

## রোল সিস্টেম সংক্ষেপে

| রোল | কী দেখতে পায় |
|---|---|
| গ্রাহক (Customer) | শুধু বিক্রয় মূল্য, স্টক, পণ্য বিস্তারিত |
| রিসেলার (Reseller) | ক্রয় মূল্য + বিক্রয় মূল্য দুটোই |
| অ্যাডমিন (Admin) | সব কিছু + অ্যাডমিন প্যানেল (পণ্য CRUD, স্টক, রোল ম্যানেজমেন্ট) |

## নোট

- সার্চ সিস্টেম প্রথমে ইউনিক কোড দিয়ে এক্স্যাক্ট ম্যাচ খোঁজে, না পেলে নাম/ক্যাটাগরিতে সাবস্ট্রিং সার্চ করে। কয়েক হাজার পণ্যের দোকানের জন্য এটা যথেষ্ট দ্রুত; পণ্য সংখ্যা অনেক বেশি (কয়েক লাখ) হলে ভবিষ্যতে Algolia/Typesense-এর মতো সার্চ ইঞ্জিন যোগ করা যেতে পারে।
- ছবি Firebase Storage-এ পাবলিক URL হিসেবে সংরক্ষিত হয়।
